## 正常场景

### 股票市场数据加载
#### 首屏加载
##### 打开股票市场页面首次加载数据
###### 前置条件
- 用户已登录或未登录
- 本地缓存为空或已过期
###### 测试步骤
1. 导航到股票研究页面
2. 观察页面加载状态
###### 预期结果
- 显示加载骨架屏
- 调用 listMarketStocksPage（limit=20, offset=0）
- 显示股票列表（列表模式默认）
- 显示市场概览卡片（A股/沪市/深市/北交所覆盖数）

##### 首屏加载命中 24h 缓存
###### 前置条件
- 本地缓存存在且未过期（< 24h）
###### 测试步骤
1. 打开股票市场页面
###### 预期结果
- 立即显示缓存的 exchangeCounts
- 仍调用 API 更新最新数据
- 数据返回后刷新列表

### 自选股管理
#### 自选股列表加载
##### 已登录用户加载自选股列表
###### 前置条件
- 用户已登录（authToken 有效）
- 已添加若干自选股
###### 测试步骤
1. 切换到「自选股」Tab
###### 预期结果
- 调用 listMarketWatchStocks(authToken)
- 显示自选股列表
- 列表按添加时间或排序规则展示

##### 未登录用户查看自选股显示空状态
###### 前置条件
- 用户未登录（authToken 为 null）

1. 切换到「自选股」Tab
###### 预期结果

- 显示「去股票市场添加」按钮
- 点击按钮跳转到「股票市场」Tab

#### 添加自选股
##### 从股票市场添加自选股
###### 前置条件
- 用户已登录
- 当前在「股票市场」Tab，某股票未加自选
###### 测试步骤
1. 点击股票卡片或列表行的「加入自选」按钮
###### 预期结果
- 按钮立即变为「已加入自选」且 disabled
- 乐观更新：自选股列表新增该股票
- 调用 addMarketWatchStock(authToken, stockId)
- API 成功后更新服务端返回的完整数据
- 按钮恢复可点击，文案保持「已加入自选」

##### 详情抽屉内添加自选股
###### 前置条件
- 用户已登录，打开某股票详情抽屉
- 该股票未加自选
###### 测试步骤
1. 点击抽屉底部「加入自选」按钮
###### 预期结果
- 按钮文案变为「处理中」且 disabled
- 乐观更新自选股列表
- API 成功后按钮变为「移除自选」

#### 移除自选股
##### 从自选股列表移除
###### 前置条件
- 用户已登录，在「自选股」Tab

##### 从股票市场移除已自选股票
