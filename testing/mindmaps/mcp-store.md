### 目录加载与展示

#### 首次加载目录数据

##### 打开 MCP 商店页面加载目录列表

###### 前置条件
- 用户已登录
- 网络正常

###### 测试步骤
1. 导航到 MCP 商店页面

###### 预期结果
- 页面正确加载 MCP 目录列表
- 展示 MCP 卡片，每张卡片包含名称、描述、来源标签、安装状态标签
- 顶部统计指标卡展示总目录、系统预置、云端目录、已安装、已启用五项数据

##### 有快照缓存时先展示缓存再后台刷新

###### 前置条件
- 用户之前访问过 MCP 商店页面，本地有快照缓存
- 网络正常

###### 测试步骤
1. 导航到 MCP 商店页面

###### 预期结果
- 页面立即展示缓存的目录数据，无 loading 骨架屏
- 后台静默刷新完成后，页面数据更新为最新

#### 统计指标准确性

##### 验证五项统计指标与列表数据一致

###### 前置条件
- MCP 目录已加载完成
- 存在不同类型的 MCP（bundled、cloud、已安装、未安装）

###### 测试步骤
1. 查看页面顶部五个指标卡
2. 逐一比对："总目录"与卡片总数、"系统预置"与 bundled 标签数、"云端目录"与云端来源数、"已安装"与已安装标签数、"已启用"与启用中状态数

###### 预期结果
- 五项指标数值均与实际列表数据一致
